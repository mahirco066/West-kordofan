# موقع مركز دراسات السلام والتنمية — نسخة مؤسسية متكاملة

## ما الذي تم إضافته؟
- Backend حقيقي باستخدام Node.js + Express.
- قاعدة بيانات SQLite.
- تسجيل دخول آمن للوحة الإدارة باستخدام bcrypt.
- إدارة الأخبار (إضافة/حذف + رفع صورة).
- إدارة البحوث والإصدارات (إضافة/حذف + رفع PDF/Word).
- إدارة البرامج.
- استقبال رسائل "اتصل بنا" داخل لوحة التحكم.
- تغيير كلمة مرور المدير.
- واجهة عامة تقرأ المحتوى من قاعدة البيانات.
- مجلد DATA_DIR مستقل لحفظ قاعدة البيانات والملفات المرفوعة.

## تشغيل الموقع
1. ثبّت Node.js 18 أو أحدث.
2. افتح الطرفية داخل مجلد المشروع.
3. نفّذ:
   npm install
   npm start
4. افتح:
   http://localhost:3000
5. لوحة التحكم:
   http://localhost:3000/admin

## بيانات الدخول الافتراضية
اسم المستخدم: admin
كلمة المرور: Admin@2026

غيّر كلمة المرور من لوحة التحكم فوراً.

يمكن تغيير بيانات الدخول الأولية قبل التشغيل عبر متغيرات البيئة:
ADMIN_USERNAME
ADMIN_PASSWORD
SESSION_SECRET

## التخزين الدائم
قاعدة البيانات والملفات تحفظ داخل:
data/center.db
data/uploads/

على الاستضافة يجب ربط `DATA_DIR` بقرص/Volume دائم؛ وإلا قد تضيع البيانات عند إعادة إنشاء الخدمة.

## ملاحظة
هذه نسخة مؤسسية أولى. قبل استخدامها كنظام إنتاج فعلي، يوصى بإضافة HTTPS، نسخ احتياطي دوري، صلاحيات متعددة للمستخدمين، وسجل تدقيق للعمليات.
